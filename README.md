# CP Fondue - ระบบแจ้งซ่อมออนไลน์ (วิทยาลัยการคอมพิวเตอร์ มข.)

ระบบบริหารจัดการและติดตามงานแจ้งซ่อมแบบครบวงจร พัฒนาด้วย Next.js (App Router), Prisma ORM และ PostgreSQL

---

## 🚀 วิธีติดตั้งและเปิดใช้งาน (Getting Started)

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. ตั้งค่าฐานข้อมูล (.env)
สร้างหรือตรวจสอบไฟล์ `.env` ในโฟลเดอร์โปรเจกต์:
```env
DATABASE_URL="postgresql://user:password@localhost:5432/cp_fondue?schema=public"
```

ซิงค์ Schema และลงข้อมูลเริ่มต้น (Seed Data):
```bash
npx prisma db push
npm run seed
```

### 3. เริ่มต้นรันโปรเจกต์
```bash
npm run dev
```
เปิดบราวเซอร์ที่: **[http://localhost:3000](http://localhost:3000)**

> **คำสั่งช่วยเหลือเพิ่มเติม:**
> - `npm run db:clear` : เคลียร์ข้อมูลคำร้องแจ้งซ่อม ประวัติ และการเบิกทั้งหมด เพื่อเริ่มทดสอบใหม่ตั้งแต่ศูนย์
> - `npm run db:reset` : ล้างข้อมูลทั้งหมดและ Seed ข้อมูลตัวอย่างเริ่มต้นใหม่

## ⚙️ การทำงานของฟังก์ชันหลัก (Core Workflows)

### 1. 📝 การส่งใบแจ้งซ่อม (Create Ticket)
- เข้าที่หน้า `/reporter` (หรือเมนูแจ้งซ่อมของเจ้าหน้าที่/ช่าง)
- **เลือกห้อง/สถานที่**: ระบบจะกรองและแสดงเฉพาะ **ครุภัณฑ์/อุปกรณ์ที่อยู่ในห้องนั้น** ในช่องเลือกอุปกรณ์อัตโนมัติ (หรือเลือกไม่ระบุครุภัณฑ์หากแจ้งซ่อมสถานที่ทั่วไป)
- กรอกรายละเอียดปัญหา และแนบรูปถ่ายความเสียหาย (1-3 รูป)
- กด **"ส่งใบแจ้งซ่อม"** ระบบจะสร้างรหัสคำร้องอัตโนมัติ (เช่น `REQ-202610-0001`) และส่งไปยังโต๊ะคัดกรองของเจ้าหน้าที่ทันที

### 2. 📋 เจ้าหน้าที่คัดกรองและมอบหมายงาน (Admin Dispatch)
- เข้าที่หน้า `/admin` -> เมนู **"โต๊ะคัดกรองและจ่ายงานช่าง"**
- ตรวจสอบคำร้อง รายละเอียดสถานที่ และรูปถ่ายความเสียหาย
- **มอบหมายช่าง**: สามารถเลือกช่างรับผิดชอบได้ **หลายคนพร้อมกัน** เพื่องานที่ต้องทำเป็นทีม (ช่างคนแรกจะเป็นช่างหลัก)
- **กำหนด Tags ลำดับความสำคัญ**: กำหนด Tags (เช่น *งานด่วนที่สุด*, *กระทบวงกว้าง*, *งานจำเป็น*) ซึ่งระบบจะใช้จัดลำดับความสำคัญในคิวงานช่างโดยอัตโนมัติ
- กดยืนยันมอบหมายงาน สถานะของคำร้องจะเปลี่ยนเป็น `ASSIGNED`

### 3. 🔧 ช่างกดรับงานและปิดงาน (Technician Field Desk)
- เข้าที่หน้า `/technician`
- **คิวงานช่าง**: แสดงรายการงานเรียงตามลำดับความสำคัญของ Tags (มี Dropdown ให้สลับดูคิวงานของช่างแต่ละคน หรือดูภาพรวมทั้งระบบได้)
- **กดรับงาน**: ช่างกดปุ่ม **"ยืนยันรับงาน"** สถานะจะเปลี่ยนเป็น `IN_PROGRESS` (กำลังเข้าซ่อม)
- **ปิดงานซ่อม**: เมื่อซ่อมเสร็จ ช่างแนบรูปถ่ายผลงานหลังซ่อมและบันทึกข้อความสรุป แล้วกด **"ปิดงานซ่อม"** สถานะจะเปลี่ยนเป็น `COMPLETED`
- **ไฮไลต์งานที่เสร็จแล้ว**: รายการที่เสร็จสิ้นจะมี **พื้นหลังสีเขียว** ชัดเจน และถูกจัดเรียงย้ายลงไปอยู่ **ด้านล่างสุดของคิวงาน** ทันที
- **การประเมิน**: ผู้แจ้งซ่อมสามารถให้คะแนนความพึงพอใจ (1-5 ดาว) พร้อมข้อเสนอแนะได้ที่หน้า `/reporter`

### 4. 📦 การเบิกจ่ายพัสดุ/อะไหล่ (Spare Parts Requisition)
- **ช่างขอเบิกอะไหล่**: ที่หน้า `/technician` ช่างสามารถส่งคำขอเบิกอะไหล่ที่ต้องใช้ในงานซ่อม ระบุรายการและจำนวน
- **เจ้าหน้าที่พิจารณา**: ที่หน้า `/admin` -> เมนู **"งานพัสดุและเคาน์เตอร์เบิกจ่าย"** การ์ดด้านบนจะแสดงจำนวนคำขอรออนุมัติแบบ Real-time
- **อนุมัติเบิกพัสดุ**: เมื่อเจ้าหน้าที่กดยืนยันอนุมัติ ระบบจะตัดยอดคงเหลือในคลังพัสดุอัตโนมัติ และบันทึกประวัติลงใน **"ตารางรวมประวัติการเบิกพัสดุที่อนุมัติแล้ว"** ด้านล่างทันที
